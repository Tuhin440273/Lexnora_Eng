## Phase 3 contents

- Admin area at `/admin` (middleware `can:access-admin`): overview, categories, courses (search and filters), chapters, lessons, sentences, words and phrases, audio library.
- Every action is authorized by `ContentPolicy` (permissions `content.manage`, `content.publish`, `audio.manage`). The super-admin passes every check.
- Form Requests validate every input. Protected fields (`is_published`, `created_by`, `sort_order`, `lesson_id`, `parent_id` on update) are never taken from the request.
- Deleting content soft-deletes everything below it (`ContentDeletionService`).
- A lesson needs at least one sentence before it can be published. Learners see a lesson only when lesson, chapter and course are all published.
- Audio: extension and server-detected MIME type must both be audio, size limit from `AUDIO_MAX_KB` (default 10 MB), file name generated by the server. Files are streamed through `route('audio.stream')` with a permission check and range support, so no `storage:link` is needed.
- Course thumbnails are streamed the same way (`route('courses.thumbnail')`).
- Roles and permissions are shared with the React app (`auth.roles`, `auth.permissions`, `auth.can_access_admin`) to show or hide menu items only.
- Theme: Indigo primary, slate neutrals, Inter font.
